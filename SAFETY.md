# Electrical Safety

This project interfaces with AC mains voltage. Mains electricity can cause severe injury, fire, or death.

- Do not work on energized circuits unless you are qualified and using appropriate protective procedures.
- Use properly rated isolation, fuses, enclosures, terminals, and test equipment.
- Keep low-voltage microcontroller circuitry electrically isolated from hazardous mains conductors where required.
- Verify the voltage/current sensor modules and relay modules are rated for the intended application.
- Never rely on this prototype as a certified protection, billing, or safety system.
- Disconnect power before changing wiring.

The repository is provided for educational and prototyping purposes. Anyone reproducing the hardware is responsible for safe implementation and compliance with local electrical regulations.
